# 🏕️ Camping E-Commerce WordPress Store

Boutique en ligne WordPress spécialisée dans la vente de produits de camping et d’outdoor, développée avec WooCommerce.

---

## 📌 Description

Ce projet est un site e-commerce basé sur WordPress permettant de vendre des produits liés au camping :

- Tentes et équipements de camping  
- Sacs de couchage  
- Lampes et accessoires outdoor  
- Matériel de randonnée  
- Produits de survie  

Le site utilise **WooCommerce** pour gérer les produits, les commandes et les paiements.

---

## ⚙️ Technologies utilisées

- WordPress CMS  
- WooCommerce  
- PHP  
- MySQL  
- Thème WordPress  
- Plugins (SEO, sécurité, cache, paiement)  
- Stripe / PayPal (paiement en ligne)

---

## 🚀 Fonctionnalités

- 🛍️ Boutique en ligne complète  
- 🛒 Panier et commande  
- 👤 Comptes utilisateurs  
- 💳 Paiement sécurisé  
- 📦 Gestion des produits et stocks  
- 🔍 Recherche et filtres produits  
- 📱 Design responsive  

---

## 📂 Structure du projet

- wp-content/ (themes, plugins, uploads)  
- wp-admin/  
- wp-includes/  
- wp-config.php  
- index.php  

---

## 🛠️ Installation

1. Installer WordPress sur un serveur local (XAMPP / WAMP / Laragon)  
2. Créer une base de données MySQL  
3. Installer WordPress  
4. Installer WooCommerce depuis les plugins  
5. Activer le plugin et configurer la boutique  

---

## 🛒 Ajout des produits

Dans le tableau de bord WordPress :

- Products → Add New  
- Ajouter nom, prix, images, description et stock  

---

## 🔐 Sécurité

- Activer HTTPS (SSL)  
- Installer un plugin de sécurité (Wordfence recommandé)  
- Faire des sauvegardes régulières  

---

## 🎯 Objectif

Créer une boutique en ligne professionnelle pour la vente de produits de camping avec une gestion simple et efficace via WordPress + WooCommerce.
